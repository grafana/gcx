# k6

Terms for Grafana Cloud k6 performance testing.

**Load test**:
A k6 Cloud test definition, made of a script and its settings, that belongs to a project. Test runs refer to it as `test_id`.
_Avoid_: test (on its own, where a test run could be meant), script (the script is one part of a load test)

**Test run**:
One execution of a load test in k6 Cloud, with its own status, result and results data.
_Avoid_: job, execution

**Run status**:
Where a test run is in its lifecycle: `created`, `queued`, `initializing`, `running`, `processing_metrics`, `completed` or `aborted`.
_Avoid_: state, result (for the lifecycle)

**Run result**:
The outcome of a finished test run: `passed`, `failed` when thresholds were breached, or `error` when the run could not complete. An unfinished run has no result.
_Avoid_: status (for the outcome), result status (the integer field older k6 APIs returned)
