# Glossary

Shipped domain terms, one file per context. Read this map, then only the
context files a change touches. Proposed terms stay in their RFC until the
feature ships; then they move here.

| Context | File | Covers |
|---------|------|--------|
| Alerting | [alerting.md](alerting.md) | Notification routing: routing trees, notification policies, receivers, integrations |
| k6 | [k6.md](k6.md) | Grafana Cloud k6: load tests, test runs, run status and results |

## How the contexts relate

Alerting and k6 share no terms. When another context is added, note here
which terms it shares with existing contexts and which context owns each one.
